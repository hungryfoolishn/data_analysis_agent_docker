## 四、我建议采用新的推进原则

后续每个批次都以最终交付能力验收，而不是以代码提交数量验收。

例如：

- B1 不只是实现 SnapshotStore，而是能够可靠保存、恢复和校验数据快照。
- B3 不只是实现 AssetResolver 接口，而是 SQLite 查询结果能够真正进入 Runtime 分析执行。
- B4 不只是 Planner 和 Report 接口打通，而是用户上传 CSV 后能完成真实分析并生成报告。
- B6 不只是测试通过，而是建立可重复运行的 10 datasets / 30 questions 质量基线。
- B8 不只是 Adapter 数量达标，而是数据能够刷新、追溯、标准化。
- B9/B10 不只是增加 Prompt 或 Skill，而是形成真正可用的领域分析能力。
- B11 不只是多个 Agent 协作，而是通过实验证明协作质量超过单 Agent 基线。
