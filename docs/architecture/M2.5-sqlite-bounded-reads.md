# M2.5: SQLite 有界读取与 DataFrame 物化

## 范围

M2.5 在 M2.3 只读连接和 M2.4 Schema Introspection 之上增加 SQLite 数据读取能力：

- `SQLiteDataSource.preview(rows, table_name=..., columns=..., order_by=...)`
- `SQLiteDataSource.preview_with_metadata(...)`
- `SQLiteDataSource.estimate_rows(table_name, exact=False)`
- `SQLiteDataSource.materialize(...)`
- `SQLiteDataSource.materialize_with_metadata(...)`
- `SQLiteDataSource.execute_bounded_query(...)`

这些方法继续返回或围绕 Pandas DataFrame 工作；`*_with_metadata` 方法返回
`BoundedReadResult`，其中包含截断状态、行数上限、耗时、来源身份和查询指纹。

## 读取边界

### 表读取

表名必须来自 `introspect_schema()` 返回的 ordinary user table 清单。列投影和排序列
也必须匹配该表的 introspected columns。SQLite identifier 统一使用双引号转义，
不把用户输入直接拼入 SQL。

数据库包含多个表时，`table_name` 必须显式传入；只有一个用户表时可以省略。

### SQL 查询

`execute_bounded_query()` 与 `materialize(query=...)` 只接受单条 SELECT/CTE 查询。
实现同时使用：

- SQLite `mode=ro`
- `PRAGMA query_only=ON`
- `set_authorizer()` 允许 SELECT/READ，并拒绝 DML、DDL、PRAGMA 和其他 action
- 顶层语句分隔符检查，拒绝多语句
- 查询参数只通过绑定参数传入

原始 SQL 不写入读取元数据，只保存 SHA-256 查询指纹。

## 资源限制

`SQLiteConnectionConfig` 新增：

- `preview_max_rows`：预览硬上限，默认 100
- `materialize_max_rows`：物化硬上限，默认 100,000
- `query_timeout_seconds`：SQLite progress handler deadline，默认 30
- `max_result_bytes`：物化结果的估算字节上限，默认 50 MiB；不是硬性 SQLite/Python 峰值内存边界
- `fetch_batch_rows`：`fetchmany()` 批大小，默认 1,000

调用方请求的 `max_rows` 不能超过对应系统硬上限。读取循环最多额外探测一行；
发现 `max_rows + 1` 时只保留前 `max_rows` 行并设置 `truncated=True`。

`max_result_bytes` 是按 SQLite 返回值内容估算的物化字节上限，读取循环逐行累计，
超过限制时抛出 `ResultSizeLimitExceededError`。SQLite 必须先返回一行，Python 才能
检查其中的字节，因此该限制不能宣称是 SQLite 内部或 Python 峰值内存的硬边界。
调用方应对大 BLOB/TEXT 使用列投影，避免读取不需要的大字段。为降低任意 SQL 的
超大单值风险，authorizer 会预先拒绝 `randomblob`、`zeroblob`、`readfile` 和
`writefile`；普通超大列值仍只能在返回后按估算值拒绝。

执行超时抛出 `QueryTimeoutError`。progress handler 和 authorizer 在 finally 阶段
清理，短生命周期连接总是关闭。

## 行数估算

`estimate_rows()` 返回 `RowEstimate`：

- `count`：行数；未知时为 `None`
- `is_exact`：是否精确计数
- `source`：`sqlite_stat1`、`exact_count` 或 `unknown`

非精确估算优先读取已存在的 `sqlite_stat1` 统计。`exact=True` 时执行带超时限制的
`SELECT COUNT(*)`。

## M2.6 边界

M2.5 不注册 Runtime V2 DataAsset，不生成 Evidence、Findings 或 Report Claims。
`SQLiteReadMetadata` 保留了后续建立查询结果资产所需的数据库路径、表名、查询指纹、
列集合、行数、截断状态和耗时；M2.6 将在其上补充完整 provenance、内容 hash 与去重。
