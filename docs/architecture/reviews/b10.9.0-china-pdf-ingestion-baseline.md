## 1. Current State

### China adapter capabilities

- `china_documents.py` implements announcement discovery (`parse_china_announcement_list`)
  with CNINFO POST query, validated live at B10.8 (announcement ID `1222155729`).
- `parse_china_statement_csv` handles official CSV/TSV exports for deterministic tests.
- `china_fact_to_row` maps parsed facts into canonical acquisition rows.
- **PDF parsing is NOT implemented** - detected as `unsupported` and rejected.

### Dependencies

- `pdfplumber` 0.11.10 installed on docker host (analysis env, Python 3.10.18).
- Not yet in `requirements.txt` - must be added.
- No OCR dependency installed; scanned PDFs remain out of scope (P2).

### Canonical model constraints

- `FinancialStatement` (B10.2) requires ISO dates, `StatementTypeKind` (income/balance/cash),
  `PeriodTypeKind` (instant for balance, duration for income/cash).
- `FinancialLineItem` uses `canonical_concept` (snake_case), `Decimal` value, `unit`.
- `china_fact_to_row` produces canonical rows for `AcquisitionService.acquire()`.

### Existing acquisition path

- `AdapterRegistry` -> `AcquisitionService.acquire(FetchRequest)` -> `DataAsset` -> `SnapshotStore`.
- SEC adapter already goes through this path with source_metadata.
- China PDF facts must follow the same path (no parallel storage).

## 2. Design Decisions

| Area | Decision | Rationale |
|---|---|---|
| PDF library | `pdfplumber` (MIT) | Lightweight text+table extraction, Python 3.10 compatible |
| OCR | Not implemented (P2) | Text-based annual reports are the primary source; OCR adds heavy system deps |
| Module location | `runtime/financial/china_pdf.py` | Follows existing flat module pattern |
| Mapping | `CN_SUBJECT_MAP` in same module | Direct mapping, versioned; avoids premature catalog refactor |
| Integration | Via existing `china_fact_to_row` + `AcquisitionService` | No parallel systems |
