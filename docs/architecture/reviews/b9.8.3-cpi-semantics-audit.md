# B9.8.3 CPI 统计口径审计报告

日期：2026-11-16
分支：`codex/phase1-m2.4-sqlite-schema`
基线 HEAD：`63a6a3b`（= 远端最新提交）

## 1. 问题根因

`langgraph_langchain/runtime/macro/comparison.py` 的 `_leg_rate_series()`（当前实现第 217-247 行附近）：

```python
if leg.indicator.level_kind == "growth_rate":
    # Published YoY rate: use as-is, never re-diff.
    return prepared, disclosures
```

该分支把"`level_kind == growth_rate`"等价于"值已经是同比百分比"。但统计口径（statistic kind）与 `level_kind` 不是同一概念：

- **美国 CPI**（`us_cpi_monthly`）：`unit="index_1982_1984_100"`、`level_kind="index"`、`price_basis="index"`。原始数据是 CPI 指数水平（1982-84=100），经 `apply_macro_transform(transform="yoy")` 以 PeriodIndex lag-12 计算 `(CPI_t/CPI_{t-12}-1)*100`，输出真正的**同比百分比（percent）**。转换正确。
- **中国 CPI**（`cn_cpi_yoy_annual`）：`unit="same_period_last_year_100"`、`level_kind="growth_rate"`、`base_period="same_period_last_year"`。NBS 发布口径为**以上年同期为 100 的同比指数**：100.2 表示同比 +0.2%，99.8 表示 −0.2%，100 表示零增长。该数据命中 `growth_rate` 分支被**原样透传**，值仍停留在 ~100 的指数量纲。

结果：G15 对齐资产把美国的同比百分比（~+2.4%）与中国的同比指数值（~100.3）直接并列比较，数值口径不一致——正是本 P1。

## 2. 涉及的生产调用链

```
MacroRuntimeIntegration.run()
  → ComparisonSpec → CrossCountryComparator.resolve()
      → _leg_rate_series()          ← 缺陷点：growth_rate 无条件透传
      → _normalize_frequency()      （频率归一，均值不改变量纲错误）
      → 对齐帧构建（ ConceptComparison.aligned_values ）
  → MacroRuntimeIntegration.build_aligned_asset()   （metadata 未记录统计口径）
  → build_comparison_plan → Runtime V2 → run_analysis_operation
  → Evidence（输入含两国源资产与对齐资产）→ Verified Report
```

数值错误沿该链路传播至对齐资产、correlation 步骤输出与 Verified Report。

## 3. 错误数值如何产生（fixture 实证）

`tests/test_macro_cross_country.py` CN fixture（NBS 同比指数）：`[102.0, 100.2, 100.3, 99.8]`。

- 现有单元测试断言 `frame.loc["2025", "cpi_cn"] == pytest.approx(99.8)` —— 把指数值 99.8 当作同比速率记录（错误语义被测试固化）。
- `tests/integration/macro/test_runtime_e2e.py:106` 断言 `95.0 < value < 105.0` —— 只验证"值在指数量纲附近"，恰好掩盖了量纲错误；US 侧 ~2.4 的真实同比百分比反而不满足该断言对象（测试只检查了 CN 列）。
- B9.8.2 验收报告 §6 的 G15 数值示例（"CN 99.8 为 published-rate range"）同样承载了错误语义，需要修订。

## 4. 影响范围

- 目录中**唯一**命中"同比指数"口径的指标是 `cn_cpi_yoy_annual`（`grep same_period_last_year_100` 仅 1 处）。
- 受影响场景：所有涉及 CN CPI 腿的跨国家比较（G15 及未来的中美 CPI 对比）；单国家分析（inflation 模板）只对 CN CPI 做 rolling_average/period_comparison（level_kind 守卫阻止二次同比），不经过比较管线，不受影响。
- G16（GDP）不受影响：两国 GDP 均为 level_kind="level"，走 yoy 变换路径。
- 其他指标无相同单位语义问题（无其他 `*_100` 类同比单位；BEA personal income、失业率、非农等均为水平量）。

## 5. 修复方案

1. **统计口径建模**（阶段 1）：新增 `StatisticKind`（`level / index_level / yoy_index / yoy_rate / mom_rate / qoq_rate / unknown`）；`MacroIndicator` 增加可选 `statistic_kind` 字段（None = 未声明）；`resolve_statistic_kind(indicator)` 显式解析：显式声明优先，未声明时按 `level_kind × 已知单位常量` 的白名单规则推导（非模糊字符串嗅探），推导不出 → `unknown`。`catalog.json` 为全部 13 个指标补写显式 `statistic_kind`。
2. **统一转换出口**（阶段 1/2）：新增纯函数 `normalize_to_yoy_rate(frame, indicator, ...)` → `NormalizedRateResult(dataframe, input_statistic_kind, output_statistic_kind="yoy_rate", output_unit="percent", conversion_method, warnings, indicator_id, transform_version)`。转换表：`yoy_rate` 透传（不重复减 100）；`yoy_index` 减 100（NaN 保持 NaN，绝不变成 −100；非正/非有限值拒绝）；`index_level` 走既有 PeriodIndex 感知 yoy；`level/mom_rate/qoq_rate/unknown` → 显式拒绝，不猜测。
3. **比较引擎接入**（阶段 2）：`_leg_rate_series()` 改为经过 `normalize_to_yoy_rate` 统一出口；`rate_nature` 按 statistic_kind 派生；对齐资产 metadata 记录 `output_statistic_kind / output_unit / input_statistic_kinds / conversion_methods / transform_version`。
4. **测试修复**（阶段 3）：替换范围断言为 fixture 精确值断言（`100.0→0.0、100.2→0.2、101.5→1.5、102.5→2.5、99.8→-0.2` 参数化）；G15 E2E 验证两侧统一为 yoy_rate/percent 且精确数值来自 fixture；G16 回归确认阻断行为不变。

## 6. 风险

- `statistic_kind` 为新增可选字段：旧 catalog（无该字段）经 `resolve_statistic_kind` 推导保持兼容；`MacroIndicator` 校验器需容忍未知值并显式拒绝非法字面量。
- `yoy_index − 100` 只在明确识别为"上年=100"口径时执行；不能因 unit 字符串含"100"而触发。
- 美国指数 yoy 既有实现满足 §4.2 要求（PeriodIndex、非 row-shift、缺基期返回缺失、重复期间快速失败、结果为 percent），本轮只需锚定测试，不需改动。
- 对齐资产 metadata 字段扩展属于纯增量，`source_metadata` 为自由 dict，不破坏 B8/B11.2 契约。

## 7. 测试计划

- 新增 `tests/test_macro_statistics.py`：参数化同比指数转换、NaN/inf/负值/未知口径拒绝、yoy_rate 透传不重复转换、index_level 转换、转换元数据。
- 更新 `tests/test_macro_cross_country.py`：CN 期望值改为减 100 后的精确速率；透传断言改为口径断言。

- 回归：Macro 全套件、integration/macro、B8/B11.2/B4/B6、全量套件与基线 `22a93d0` 同环境同命令对比。

## 8. 同类问题排查结论

对 `catalog.json` 全量核查：无其他指标使用"上年=100"或类似同比指数单位；`level_kind="growth_rate"` 仅 `cn_cpi_yoy_annual` 一个。修复后 `unknown` 口径一律阻断的策略可防止未来新增指标再犯同类错误。
