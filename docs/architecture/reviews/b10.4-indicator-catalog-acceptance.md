## 1. Implementation

`langgraph_langchain/runtime/financial/catalog.py` provides the typed canonical indicator catalog.

- Metric identity is `metric_id + market_scope`; market-specific definitions cannot silently replace `any`.
- Raw, ratio, and growth metric kinds are explicit.
- Definitions carry statement type, canonical concept, statistic kind, unit, period requirement, dependencies, and version.
- No fuzzy string lookup is used.
- Computation is Decimal-based.
- Missing values return `unavailable`; zero denominator or zero growth baseline returns `invalid`.
- Ratio and growth semantics are explicit and do not reuse legacy float calculations.
