## 1. 问题根因

`comparison.py::_leg_rate_series` 把 `level_kind == "growth_rate"` 等价于"同比百分比"并无条件透传。中国 NBS CPI（`cn_cpi_yoy_annual`，`unit="same_period_last_year_100"`）实际是"以上年同期为 100"的同比**指数**（100.2 = +0.2%，99.8 = −0.2%），被原样放进对齐帧与美国同比**百分比**（~+2.4%）并列，量纲不一致。完整根因链见审计报告。

## 2. 修复方案

1. 新增统计口径层 `langgraph_langchain/runtime/macro/statistics.py`：
   - `StatisticKind = level | index_level | yoy_index | yoy_rate | mom_rate | qoq_rate | unknown`；
   - `MacroIndicator.statistic_kind` 可选显式字段（catalog 已为全部 13 个指标显式声明）；
   - `resolve_statistic_kind()`：显式声明优先，旧数据按"level_kind × 已知单位常量"白名单推导（仅 `growth_rate` 族内精确匹配 `same_period_last_year_100`/`percent`），其余一律 `unknown`，不猜测；
   - `normalize_to_yoy_rate()` 统一转换出口，`NormalizedRateResult` 记录输入/输出统计口径、输出单位、转换方法、版本、warnings；不修改输入帧。
2. 比较引擎唯一出口：`_leg_rate_series()` 全部经由 `normalize_to_yoy_rate`；`CountryAssetLeg.rate_nature` 按 statistic_kind 派生（yoy_index/yoy_rate/index_level → rate；level 携带价格口径 real/nominal）。
3. 对齐资产 metadata 增加统计口径血缘：`output_statistic_kind="yoy_rate"`、`output_unit="percent"`、`input_statistic_kinds`（逐指标）、`conversion_methods`（逐指标转换方法）、`transform_version="b9.8.3.0"`。
4. `MacroRuntimeIntegration._comparison_summary` 暴露上述字段供验收断言。

## 3. 转换规则（冻结）

| 输入 statistic_kind | 转换方法 | 输出 |
|---|---|---|
| `yoy_rate`（percent） | `passthrough_yoy_rate`（绝不再减 100/重差分） | yoy_rate / percent |
| `yoy_index`（上年=100） | `yoy_index_minus_100`：value − 100.0 | yoy_rate / percent |
| `index_level`（指数水平） | `index_level_yoy_period_lag_transform`（PeriodIndex lag） | yoy_rate / percent |
| `level`（水平量） | `yoy_period_lag_transform`（价格口径随腿携带：real/nominal） | yoy_rate / percent |
| `mom_rate` / `qoq_rate` / `unknown` | **显式拒绝**（`StatisticSemanticsError`） | 不转换 |

保护规则：NaN 保持 NaN（绝不变成 −100）；inf 拒绝；同比指数非正值拒绝；输入帧不被修改；重复期间由解析层均值合并 + 变换层快速失败双重防护。
