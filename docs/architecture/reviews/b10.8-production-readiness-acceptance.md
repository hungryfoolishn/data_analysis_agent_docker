## 3. Stage Results

### B10.8.1 - SEC Company Concept raw parser

- `langgraph_langchain/runtime/financial/sec_raw.py` now parses the real SEC
  Company Concept JSON envelope: taxonomy, tag, entityName, units and facts.
- Every parsed fact carries accession number, filing date and
  `source_response_hash`, providing full traceability for B10.6 evidence
  linkage and downstream re-verification.
- Duration and instant period types are preserved without coercion.

### B10.8.2 - China announcement / document ingestion

- `langgraph_langchain/runtime/financial/china_documents.py` introduces a
  separate announcement layer (`parse_china_announcement_list`) distinct from
  the financial fact layer.
- Announcement id, https document URL, date, title and response hash are
  captured for every parsed item.
- The PDF filing-document financial parser is NOT implemented; the live China
  gate is therefore recorded as BLOCKED, not passed.

### B10.8.3 - Period semantics

- `langgraph_langchain/runtime/financial/periods.py` rejects derivation of
  single-quarter values from cumulative periods when intermediate cumulative
  periods are missing (e.g. `FY - Q1` no longer fabricates a Q4 value).
- Filing-version mismatch between cumulative and derived periods is rejected
  so amendments cannot silently mix periods.
- `tests/test_financial_periods.py` covers both rejection paths.

### B10.8.4 - Runtime Evidence integration

- Platform mode is explicit in `runtime_integration.py`; offline/platform
  distinction is enforced by `context.py`.
- `evidence.py` preserves `Decimal` values in the evidence payload instead of
  collapsing financial amounts to `float`; precision semantics remain intact.
- `langgraph_langchain/evidence/registry.py` registration goes through the
  existing EvidenceRegistry contract - no parallel evidence system.

### B10.8.5 - Golden expansion

- `tests/fixtures/financial/b10_golden.json` expanded to 20 cases: 10 success
  and 10 rejection cases.
- Success cases cover raw-source end-to-end (SEC/China shape, USD/CNY,
  duration/instant, cumulative/single-quarter, evidence binding).
- Rejection cases cover missing intermediate periods, filing-version mismatch,
  unknown statistic kind, currency mismatch and invalid period shapes.
- Financial regression after expansion: **423 passed / 0 failed**.

### B10.8.6 - External smoke validation

- `tests/external/financial/test_financial_external_smoke.py` is opt-in via
  `RUN_FINANCIAL_EXTERNAL_SMOKE=1` and never runs in the offline suite.
- One bounded request per source; responses are size-limited and hashed.
- SEC smoke exercises raw parsing AND the full production acquisition path
  (`AdapterRegistry` -> `AcquisitionService` -> DataAsset/SnapshotStore) for
  both duration (`Revenues`) and instant (`Assets`) concepts.
