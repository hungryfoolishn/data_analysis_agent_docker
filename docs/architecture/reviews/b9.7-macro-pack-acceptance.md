## 2. Runtime 调用链（B9.4 实测）

```
User Question
  → MacroIntentResolver.resolve() → MacroIntent{concepts, countries, years}
  → MacroRuntimeIntegration.run()
      → build_data_requirements → FetchRequest per indicator
      → AcquisitionService.acquire() → FetchResult → runtime.register_fetch_result()
      → AssetResolver._resolve_snapshot_asset() → DataFrame
      → check_data_sufficiency → ready/partially_ready/blocked
      → build_template_plan → GeneralAnalysisPlan v2（含 macro_transform 步骤）
  → general_plan_to_runtime_plan → validate_runtime_plan
  → initialize_plan → Scheduler → Runner → StructuredTaskExecutor
      → execute_analysis_operation(operation="macro_transform") → 转换结果
      → OutputAssetBinding（{step_id}.{output_name} 引用解析）
  → record_execution_result → Evidence（canonical + verify）
  → build_verified_report → Report（含来源披露）
```
