## 3. Protocol Summary

- Job envelope: `{"protocol_version":"1","kind":"job","job":<WorkerJob JSON>}` written to `/job/input/job.json` (staged copy, never user path).
- Result envelope: exactly ONE JSON line on worker stdout; stderr carries logs only.
- Fail-closed parsing: unknown version / malformed JSON / missing fields / job_id mismatch / invalid status / oversized payload all rejected with explicit codes.
- Size caps: envelope 10 MiB, result 10 MiB, code ≤512k chars (inherited from WorkerJob), stdout/stderr ≤100k chars.
- No pickle, no live objects, no fork namespaces, no environment dumps.
