## 1. Implementation

`langgraph_langchain/runtime/financial/periods.py` is the canonical period-semantics exit.

- Uses canonical `period_start`/`period_end`, so natural and non-natural fiscal calendars share one path.
- Cumulative-to-quarter output begins after the previous cumulative `period_end` and ends at the current cumulative `period_end`.
- Requires the same entity, statement type, reporting basis, currency, statistic kind, and unit.
- Allows only additive `absolute_amount` facts for TTM.
- Requires exactly four complete cumulative quarters for TTM.
- Rejects missing quarter values, repeated cumulative periods, inconsistent starts, and invalid units.
- Every output records method, input statements, input values, output period, and version.
- Existing `PeriodNormalizer` YoY/QoQ behavior remains untouched.
