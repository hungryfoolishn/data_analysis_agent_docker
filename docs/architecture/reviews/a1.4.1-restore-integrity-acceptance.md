## 2. Implementation result

### DataAsset restore

`AnalysisRuntime._restore()` now verifies every restored DataAsset and records a trust state under `source_metadata["restore_integrity"]`:

- `VERIFIED` — file or snapshot content is present, stable, and hash-matching.
- `STALE` — content exists but does not match the recorded fingerprint.
- `UNVERIFIABLE` — expected fingerprint is absent, raw SQLite has WAL/SHM sidecars, or no supported content representation exists.
- `MISSING` — file or snapshot is absent.
- `VALIDATION_FAILED` — malformed path/reference or unstable/read/hash failure.

File assets use the existing streaming SHA-256 algorithm, augmented by a metadata stability check during the open-file read. Snapshot-backed assets use `SnapshotStore.load()` and then compare the restored DataFrame with `DataAsset.content_hash`. Raw SQLite database assets with WAL/SHM sidecars are never marked verified merely by hashing the main database file.

### Evidence restore

The runtime snapshot now persists canonical `EvidenceRegistry` records as an additive `canonical_evidence` key. Restore inserts records as `unverified` and reruns the existing verifier. Canonical evidence is marked `verified` only if references, current asset trust, execution linkage, artifact existence, and SQLite content-hash provenance all pass.

Persisted legacy `EvidenceItem.verified` is no longer inherited blindly. If source assets are missing, stale, or failed, the evidence becomes failed. Otherwise it is downgraded to unverified unless the linked original verification passed and all currently referenced executions/assets/artifacts are still valid and available. Every decision is recorded with a deterministic `VerificationResult`; repeated restore replaces, rather than duplicates, that record.

### Report trust

Runtime V2 report generation uses only currently verified canonical evidence and appends limitations for degraded restored assets. Runtime V1 validation consumes downgraded legacy statuses, so stale or unverifiable evidence cannot support numbers as verified.
