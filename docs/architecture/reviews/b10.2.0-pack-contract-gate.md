## 3. Contract 设计

新增 `langgraph_langchain/runtime/domain_packs.py`（平台中性基础设施）：

- `DomainPackContract`（frozen pydantic 模型）：`pack_id`（`^[a-z][a-z0-9_]{1,40}$`）、`pack_version`（严格 semver X.Y.Z）、`domain`（小写 token）、`supported_capabilities`（非空 token 元组）、`model_contract` / `normalization_contract`（Pack 自定义描述 dict，注册表不解释其语义）、`dependency_boundary`（声明的禁止导入根）、`registration_identity`。
- `DomainPackRegistry`：**仅显式注册**，无自动发现、无动态加载；import 无副作用、不注册任何内容；同 key 同内容幂等，同 key 不同内容显式报错（`DomainPackRegistrationError`，从不覆盖）；非法契约（非 `DomainPackContract` 实例或校验失败）在注册时拒绝。
- 该模块不 import 任何 Pack（Financial 或 Macro），冻结的 Macro 代码不依赖它。

新增 `langgraph_langchain/runtime/financial/pack.py`：

- `build_financial_pack_contract()`：`pack_id="financial"`、`pack_version="0.2.0"`（B10.2 范围：models + normalization）、capabilities 仅声明 B10.2 实际交付能力（`financial_models` / `financial_normalization`）——intent/templates/metrics-catalog 等 B10.3+ 能力**落地后才追加声明**；
- `model_contract`：权威模型（FinancialStatement/FinancialLineItem/Entity）、`numeric_type=Decimal`、instant/duration 期间语义、filing 元数据清单、legacy compat 原则；
- `normalization_contract`：单一转换出口、7 个 statistic_kind、`unknown_policy="reject (never guess)"`、币种保真（无隐式汇率转换）、血缘字段；
- `dependency_boundary=("langgraph_langchain.runtime.macro",)`——声明 + 测试强制（AST 检查）。

## 4. 注册行为

- `register_financial_pack(registry=None)`：无注册表时创建；传入显式注册表保持唯一注册点；幂等。
- 冲突行为：同 `pack_id` 不同版本/内容 → `DomainPackRegistrationError("Pack registration conflict …")`。

## 5. 测试结果

`tests/test_financial_pack_contract.py`：**19 passed**。

覆盖（任务书 §4.3 六项全对应）：
1. 正常注册（含 contract 内容断言）；
2. 幂等（同契约重复注册不膨胀）+ 冲突（不同版本/不同内容显式拒绝）；
3. 非法契约拒绝：8 组参数化字段非法用例（经构造函数路径触发校验——`model_copy(update=)` 按设计跳过校验，测试注释已说明）、非 Contract 对象拒绝、未注册查询 KeyError、frozen 不可变；
4. **Macro 隔离（AST 强制）**：遍历 `runtime/financial/**/*.py` 与 `runtime/financial_agent/**/*.py`，断言无任何 `runtime.macro` import（contract 中的边界声明是数据不是 import）；
5. 不影响 Macro Pack：注册 Financial 后 macro catalog（13 指标）与模板（含 `cross_country_comparison`）行为不变；
6. 不影响 Runtime：平台注册表 import 零副作用（fresh registry 为空）、域中立（无 Macro 契约混入）。

## 6. 门禁结论

Pack Contract 与注册机制已补齐并通过全部测试；无"只在文档声明、没有实现"的残留能力声明（capabilities 严格等于 B10.2 实际交付范围）。**B10.2.0 门禁通过**，进入 B10.2.1（基线复测 + Financial Asset Identity 冻结）。
