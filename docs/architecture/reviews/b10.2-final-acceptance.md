## 3. Financial Models

- `Entity`：以 `market / exchange / ticker / legal_name` 派生稳定内部 `entity_id`；外部权威标识保留在 `identifiers`。
- `FinancialStatement`：显式 `statement_type` 与 `period_type`；balance 强制 instant，income/cash 强制 duration；duration 必须有 `period_start`，instant 禁止 `period_start`。
- `FinancialLineItem`：Canonical 概念、`Decimal` 数值、可缺失值、`statistic_kind`、分层的 `FinancialUnit`、来源与 normalization metadata。
- `FinancialUnit`：分离 `statistic_kind / numeric_unit / currency / unit_denominator / scale`；货币数量级只作用于金额/每股金额，比率不隐式缩放。
- Filing identity：`filing_date`、`accession_number`、`source_document_id`、`amendment` 独立于报表期间；`version` 默认绑定 filing identity。
- `FinancialStatementKey`：九维逻辑键 `market / entity_id / canonical_concept / statement_type / period_type / fiscal_year / fiscal_period / reporting_basis / currency`。
- `FinancialStatementRegistry`：同源同内容幂等；同源不同内容冲突；不同 accession 保留并行版本，不覆盖历史。
- Legacy Compatibility：旧模型 → explicit adapter → canonical model → normalization；无关键身份/期间语义时拒绝；默认币种产生确认 warning；canonical → legacy 仅允许无损。

## 4. Normalization

- 统一出口：`normalize_financial_line_item()` 与 `normalize_financial_statement()`；无第二套隐式转换入口。
- `FinancialStatisticKind`：`absolute_amount / per_share / percent_ratio / times_ratio / growth_rate / yoy_index / unknown`。
- 语义转换：仅显式声明的 `yoy_index → growth_rate` 使用 base 100；`growth_rate`、`percent_ratio`、`times_ratio` 不减 100、不互相重解释；unknown 语义转换显式拒绝。
- 币种：CNY/USD 保留；跨币种必须提供 `FinancialCurrencyRate`（rate、date、source、direction、version、method）。缺 rate 时显式失败，不做自动 FX。
- 期间：statement 的 instant/duration、period start/end、fiscal year/period 原样保留，不由自然年替代。
- 血缘：每个结果记录 input/output value、unit、currency、statistic kind、conversion method、`b10.2.3` normalization version、warnings、source metadata、filing/accession 与输入版本。
- 不可变性：输入不修改；Decimal 精度保留；NaN/Infinity、非法 scale、不支持语义显式拒绝；缺失不补 0；重复执行结果一致。

## 5. Platform 与 Evidence 边界

- Financial Pack Contract 使用平台 `DomainPackRegistry` 显式注册；不建立第二套 Pack Registry。
- Financial identity 只定义领域键和版本规则；DataAsset 注册仍应走既有 `AnalysisRuntime.register_dataframe()` 快照化路径。
- 不实现平行 SnapshotStore / AssetResolver / AcquisitionService；B8 `FetchResult → AcquisitionService → SnapshotStore → DataAsset` 是原始层唯一通道。
- 不建立第二套 EvidenceRegistry；`FinancialEvidence` 保持计算明细/辅助信息；filing 与 normalization lineage 为 B10.6 Evidence 关联源资产提供必要元数据。
- AST/静态审计确认 `runtime/financial` 与 `runtime/financial_agent` 无 `runtime.macro` import；`pack.py` 中的 macro 字符串只是禁止边界声明。
