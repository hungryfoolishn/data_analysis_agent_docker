## 4. Key Audit Conclusions

1. `WorkerJob` (base) = CONTAINER_READY as the job envelope; `ProcessWorkerJob` = NOT_CONTAINER_READY (process-only, documented, excluded from the container boundary).
2. No real serialization boundary exists today; the Docker backend must add a JSON envelope protocol (no pickle across the container trust boundary).
3. `workspace_dir`/`source_path` are host-absolute paths that require manager-side translation — never job-controlled mounts.
4. Namespace continuity cannot cross containers; state policy decision scheduled at A1.4.2.2.2 (stateless-per-job default).
5. Application env cleaning (`os.environ.clear()`) is not container isolation; fork memory remains the current residual risk that container execution will eliminate.
6. `WORKER_BACKEND` selector exists but has no production callers — no Docker path can be activated today.
7. Image supply chain (base `:latest`, USER root, unpinned deps) must be redesigned for the worker image (A1.4.2.2.1).
8. Security acceptance matrix S01–S20 / C01–C08 established, all TBD; none may be flipped without evidence.
