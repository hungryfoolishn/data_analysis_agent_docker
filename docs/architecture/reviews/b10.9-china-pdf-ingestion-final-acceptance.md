## 3. Implementation

### Module: `langgraph_langchain/runtime/financial/china_pdf.py`

Two parsing strategies:

1. **Table-based** (primary for structured PDFs): uses pdfplumber `extract_tables()`,
   classifies tables by title row, supports multi-page statement continuation.
2. **Text-based** (fallback for real annual reports): parses text lines using
   subject-name matching with note-reference skipping. Handles bank-specific
   subjects, full-width punctuation, parentheses negatives, thousand separators.

### Accounting subject mapping

- `_CN_SUBJECT_MAP`: 57 standard subjects (balance 30, income 16, cash 10).
- `_EXTRA_SUBJECTS`: 27 additional bank/financial subjects.
- `MAPPING_VERSION = "b10.9.3.cn_v1"`.
- Unmapped subjects are recorded (never guessed to a similar canonical concept).

### Download module

- HTTPS-only, PDF magic bytes validation, size limit (20MB default),
  timeout, streaming download, SHA-256 content hash, safe transport injection.
