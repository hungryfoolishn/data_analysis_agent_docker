## 每日纪律

1. **动手优先于阅读**：每天至少 30 分钟在写代码/跑 demo，不是看文章。
2. **费曼输出**：每天用 5 分钟把当天学的讲给自己听（或写 3 句话笔记），讲不清=没学会。
3. **不追新框架**：这三周禁住"又出了个新 Agent 框架"的诱惑，深度 > 广度。
4. **面试前一天只做两件事**：过一遍 QA 的结论句 + demo 现场演示彩排。
